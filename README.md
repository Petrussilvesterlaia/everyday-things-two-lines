A two-line explanation of one everyday thing — a queue — for a 10-year-old, built on a single concrete analogy in line 1, with line 2 honestly naming what the analogy maps and what it leaves out. Entry for the make.fun bounty [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

## Run it

```sh
python3 main.py
```

This writes the two lines to `/output/entry.txt` and self-validates: exactly 2 lines, each exactly one sentence, none empty.
